---
코드 화면을 요즘 IDE처럼 다듬고, 자주 쓰는 기능을 넣었어요.

- **자동 완성**: HTML에서 `!` 를 치고 Tab 을 누르면 기본 구조가 들어가요. `ul>li*3` 같은 Emmet 약어도 펼쳐지고, JavaScript · TypeScript 는 코드 내용에 맞춰, Python · SQL 등은 자주 쓰는 틀을 추천해요.
- **열린 파일 탭**: 브라우저 탭처럼 위에서 파일을 오가고, 끌어서 순서를 바꿀 수 있어요.
- **오류 밑줄 · 빠른 수정**: JS · TS · Python 은 쓰는 동안 오류에 밑줄이 생기고, 고칠 방법을 바로 눌러 적용할 수 있어요.
- **자동 정렬**: `Shift + Alt + F` 로 코드를 보기 좋게 정리해요.
