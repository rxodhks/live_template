# LiveTemplate

실시간 협업이 가능한 템플릿 워크스페이스입니다. 한 화면에서 여러 사람이 **디자인 · 코딩 · 문서** 작업을 동시에 진행하고, 서로의 커서와 행동을 실시간으로 확인합니다. 모든 변경은 자동 저장됩니다.

## 빠른 시작

```bash
npm install
npm run dev        # 서버(3001) + 클라이언트(5173) 동시 실행 → http://localhost:5173
```

배포 형태로 실행하려면:

```bash
npm run build      # 클라이언트 빌드 (client/dist)
npm start          # 서버가 API + 빌드된 화면을 한 포트에서 제공 → http://localhost:3001
```

| 환경 변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | `3001` | 서버 포트 |
| `DATA_DIR` | `./data` | 데이터 저장 위치 (JSON, Yjs 바이너리, 암호화된 비밀 노트) |
| `SAVE_DEBOUNCE_MS` | `600` | 연속 입력을 묶어 디스크에 쓰는 지연 (최대 4초 안에는 반드시 저장) |

두 개의 브라우저(또는 시크릿 창)로 접속해 한쪽에서 템플릿을 만들고 **초대** 버튼의 링크로 다른 쪽을 참여시키면 협업 기능을 바로 확인할 수 있습니다.

## 요구사항 반영 현황

| 요구사항 | 구현 |
| --- | --- |
| 한 화면에서 여러 사용자가 실시간으로 템플릿 사용 | Yjs(CRDT) 기반 동시 편집. 같은 파일/문서/보드를 여러 명이 동시에 수정해도 충돌 없이 병합 |
| 각 사용자의 커서 + 커서 근처에 행동 표시 | 모든 화면에서 이름표가 달린 마우스 커서 공유. 행동(예: `⌨️ 코드 입력 중`, `언어 변경 → Python`, `➕ 사각형 추가`, `↔️ 도형 이동 중`)이 커서 옆 말풍선으로 3.5초간 표시 후 사라짐. 코드/문서 안에서는 텍스트 캐럿과 선택 영역도 이름과 함께 표시 |
| 상단 + 왼쪽 내비게이션 | 상단: 템플릿 전환, 현재 위치, 검색(⌘K), 저장 상태, 접속자, 초대, 채팅, 테마, 프로필 · 왼쪽: 아이콘 레일(기능 이동) + 탐색기 패널(모든 항목 트리, 목차/레이어, 접속자 목록) |
| 사용자별 행동 기록 타임라인 | 템플릿별/전체 타임라인. 사람·영역·검색어·중요 활동 필터, 실시간 추가, 반복 편집은 5분 단위로 ×N 병합, 참여자별 활동량 |
| 템플릿 생성 시 기능 선택(중복 가능) | 디자인/코딩/문서를 자유롭게 조합. 프리셋(웹 프로젝트, 제품 기획, 해커톤, 코딩 스터디, 회의록)으로 시작 내용 자동 생성. 설정에서 나중에 기능 추가/제거 가능 |
| 기능별 필요한 도구 | 아래 "기능별 도구" 참고 (예: 코딩 → 24개 언어 선택·변경) |
| 비밀번호로 여는 비밀 노트 | 템플릿 멤버만 목록을 볼 수 있고, 비밀번호를 입력해야 열림. 여러 명이 동시에 열어 실시간 편집. AES-256-GCM 암호화 저장 |
| 모든 것 자동 저장 | 문서·코드·디자인·설정·채팅·타임라인 모두 저장 버튼 없이 즉시 저장. 상단에 저장 상태 표시 |
| 휘발성 토스트 (페이드 아웃) | 접속/퇴장, 참여, 파일·문서·보드·비밀 노트 생성/삭제, 언어 변경, 권한 변경 등을 다른 사람에게 알림. 일정 시간 후 페이드 아웃(마우스를 올리면 일시 정지) |

## 기능별 도구

**💻 코딩**
- 24개 언어 문법 강조(JavaScript, TypeScript, Python, Java, C/C++, C#, Go, Rust, Kotlin, Swift, PHP, Ruby, SQL, HTML, CSS, …)
- 파일마다 언어 선택·변경. 언어를 바꾸면 확장자도 자동으로 따라감(`main.js → main.py`), 확장자로 새 파일의 언어 자동 선택
- JavaScript 실행(격리된 샌드박스, 5초 제한, 콘솔 출력), HTML 실시간 미리보기(CSS/JS 파일 자동 연결, 다른 사람 편집도 반영)
- 멀티 파일, 자동 완성, 괄호 매칭, 찾기, 줄바꿈/들여쓰기 설정, 파일 다운로드

**📝 문서**
- 제목/목록/체크리스트/인용/코드 블록/표/링크/형광펜/정렬, 마크다운 단축 입력
- 탐색기에 실시간 목차(클릭하면 해당 위치로 이동), 글자·단어 수와 읽는 시간
- Markdown / HTML 내보내기, 인쇄·PDF 저장, 문서 복제

**🎨 디자인**
- 무한 캔버스: 사각형·원·마름모·선·화살표·펜·텍스트·스티키 노트
- 선택/다중 선택/영역 선택, 이동·크기 조절, 채우기·선·불투명도·모서리·글자 속성, 위치/크기 수치 입력
- 레이어 목록, 순서 변경, 잠금, 복제·복사/붙여넣기, 격자/격자 맞춤, 확대/축소/화면 맞춤
- 다른 사람의 선택 영역을 색상 테두리와 이름으로 표시, 도형을 그리는 과정도 실시간 공유
- 내 변경만 되돌리는 실행 취소, SVG/PNG 내보내기

## PM 제안으로 추가한 기능

1. **초대 링크 + 권한(소유자/편집자/뷰어)** — 뷰어는 서버에서도 쓰기가 차단되는 읽기 전용
2. **따라가기(Follow)** — 팀원의 화면(위치·디자인 보드 시점)을 그대로 따라감. 발표·리뷰에 유용
3. **실시간 채팅** — 템플릿별 채팅, 읽지 않은 메시지 배지와 토스트
4. **명령 팔레트(⌘K)** — 파일·문서·보드·노트 검색, 만들기, 이동, 한글 초성 검색 지원
5. **오프라인 편집** — 연결이 끊겨도 로컬(IndexedDB)에 보관했다가 재연결 시 자동 병합
6. **"누가 어디 있는지"** — 레일 아이콘과 탐색기 항목 옆에 보고 있는 사람 표시, 자리 비움 감지
7. **비밀 노트 보안 강화** — 연속 5회 실패 시 5분 잠금, 10분 무활동 자동 잠금, 비밀번호 변경 시 열람자 강제 잠금, 실패 기록
8. **시작 프리셋** — 목적별 템플릿으로 바로 시작
9. **다크/라이트 테마**, **키보드 단축키**(`?`로 도움말)

## 아키텍처

```
브라우저 (React + Vite)                         서버 (Node + Express + Socket.IO)
 ├─ Yjs Y.Doc (템플릿 1개 = 문서 1개)  ◀─ doc:join / doc:update ─▶  DocManager (메모리 + 자동 저장)
 │   ├─ files  : 코드 파일 (Y.Text)                                   ├─ data/docs/<id>.ybin
 │   ├─ docs   : 문서 (Y.XmlFragment)                                 └─ note 문서는 AES-256-GCM 암호화
 │   └─ boards : 디자인 도형 (Y.Map)
 ├─ IndexedDB 사본 (오프라인)                  presence:* ─▶ 커서 · 보고 있는 화면 · 선택 · 행동 라벨
 ├─ CodeMirror 6 + y-codemirror.next           activity  ─▶ 타임라인 기록/병합 → 토스트 · 실시간 전파
 ├─ TipTap 3 + Collaboration                   chat:*    ─▶ 채팅 저장/전파
 └─ SVG 캔버스                                 REST /api  ─▶ 사용자 · 템플릿 · 멤버 · 초대 · 비밀 노트
```

- **동기화**: 접속할 때 상태 벡터를 교환해 서로 없는 부분만 주고받습니다(오프라인 편집 자동 병합). 이후 변경은 즉시 전송되고 서버 확인(ack)을 기준으로 "저장됨"을 표시합니다.
- **저장**: 서버는 변경을 debounce(기본 0.6초, 최대 4초)해 임시 파일에 쓴 뒤 교체(원자적 쓰기)합니다. 종료 신호를 받으면 남은 변경을 모두 저장합니다.
- **권한**: 모든 문서 쓰기는 서버가 매번 현재 권한을 확인합니다. 뷰어의 변경은 거절됩니다.

### 비밀 노트 보안

- 비밀번호는 저장하지 않습니다. `scrypt`로 **검증값**과 **암호화 키**를 서로 다른 salt로 유도하고, 검증값만 저장합니다.
- 노트 본문은 키로 **AES-256-GCM** 암호화되어 저장됩니다. 서버 디스크만으로는 내용을 읽을 수 없습니다.
- 잠금 해제에 성공하면 30분짜리 티켓을 발급하며, 키는 서버 메모리에만 존재합니다. 비밀번호가 바뀌면 모든 티켓이 폐기되고 열람자는 즉시 잠깁니다.
- 브라우저에도 사본(IndexedDB)을 남기지 않습니다.

### 코드 실행 격리

팀원이 작성한 JavaScript는 `sandbox="allow-scripts"` iframe(origin 없음) 안의 Web Worker에서 실행됩니다. 이 앱의 IndexedDB·localStorage·토큰에 접근할 수 없고, 무한 루프도 화면을 멈추지 않으며 5초 후 강제 종료됩니다.

## 알려진 한계와 다음 단계

- **인증**: 현재는 이름만으로 프로필을 만들고 토큰을 브라우저에 저장합니다. 실서비스에서는 OAuth/SSO와 계정 복구가 필요합니다.
- **저장소**: 단일 서버 + JSON 파일 저장소입니다. 규모가 커지면 PostgreSQL/S3와 Socket.IO Redis 어댑터로 수평 확장해야 합니다.
- **디자인 충돌 처리**: 같은 도형을 동시에 바꾸면 도형 단위로 마지막 변경이 반영됩니다(텍스트는 글자 단위 병합).
- **실행 가능한 언어**: 브라우저에서 실행되는 것은 JavaScript와 HTML 미리보기입니다. Python 등은 Pyodide 또는 서버 샌드박스 연동이 다음 후보입니다.
- **추가 로드맵**: 버전 스냅샷/복원, 디자인 코멘트 핀, @멘션 알림, 이미지 업로드, API 요청 속도 제한.
